# HOT / DEEP Runtime Contract

Sidecar classifies cognition; Runtime owns resources.

HOT generation-sensitive categories remain Historian, Graph Walker, Truth/Precision and opportunistic Green Room. DEEP deferred categories remain Consolidation, Reflection and Lore Study.

`toRuntimeObligation()` exposes placement, result class, soft/hard deadlines, quality weight, fallback contract, foreground sensitivity, resource hints, batching metadata, checkpoint boundary, partial-result semantics, resume identity and legal-yield metadata.

For DEEP work the obligation says where cooperative yield is legal and how a resume identity/slice is represented. `storageOwnedByRuntime: true` is explicit: Sidecar does not implement Runtime checkpoint storage, Resource Governor, worker pools or scheduling.

REQUIRED failure has a bounded fallback contract. OPPORTUNISTIC misses do not gain Context Seal authority. DEFERRED work is non-foreground and cannot enter the current foreground quorum.
