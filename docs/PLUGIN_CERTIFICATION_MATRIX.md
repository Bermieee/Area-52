# Golden-World Plugin Certification Matrix

Subsystem manifests declare `evaluationRequirements`. `GoldenWorldCertificationMatrix` records test outcomes and determines ACTIVE eligibility without granting authority itself.

The canonical Wave 1 categories are truth, history, provenance, stale/revision safety, authority, recovery, and latency/resource behavior. Subsystems may add domain-specific golden worlds.

Every mandatory test must have a passing result before ACTIVE eligibility. One failed or missing mandatory certification blocks promotion. Passing the matrix means only that the service is eligible for explicit promotion; it does not make the service a canonical owner and does not permit Context Seal or Settlement bypass.
