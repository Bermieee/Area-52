# Diagnostic Fidelity Golden Worlds

Wave 2 extends Ember Tavern / Sun Blade into a forensic world. The evaluator compares claimed reconstruction references with actual Cognitive Transactions, Context Seal receipts and Result Bus routes.

Acceptance covers source revision admission, competing evidence/Settlement decisions, historical supersession, source edit and invalidation, unresolved state, sealed context, late routing, stale routing, dependency blocking, PromptPlan omission and external Runtime/Sidecar references.

Deliberately false stories fail. A bundle that claims a late result was admitted to the sealed generation fails. A bundle with a missing required transaction fails. A wrong seal/hash or false late/stale claim fails. Transaction ordering is checked.

Fidelity evaluates observability against recorded execution; observability is not itself authority.
