# Adaptive Context Runtime Benchmarks

Wave 4 adds deterministic measurement helpers and acceptance fixtures.

Metrics include:

- semantic retention;
- current-state retention;
- historical temporal-qualifier retention;
- unresolved/contradiction retention;
- provenance/revision-reference retention;
- allocated token estimate;
- rendered byte size;
- `NO_CHANGE` reuse percentage;
- rebuild percentage;
- cache-eligible percentage;
- delivery latency input;
- fallback count;
- integrity failures;
- optional caller-supplied cost estimate.

No provider price is hard-coded.

## Golden World

The accepted Ember Tavern / Sun Blade Wave 3 sealed packet is delivered through both reference profiles. Acceptance requires different presentation/segmentation with equivalent required semantics:

- Ember Tavern remains CURRENT destroyed;
- Blade-at-Tavern remains HISTORICAL;
- current Blade location remains unknown;
- competing fate evidence remains unresolved;
- no fabricated CURRENT Blade-at-Tavern fact appears.

The harness then exercises identical-turn reuse, a revised future seal, optional-content pressure, impossible budget, post-seal injection and adapter mutation.

## Stress

The deterministic test suite plans 1,200 generation-envelope contributions, checks stable plan identity, enforces a bounded local planning threshold and verifies that the runtime does not retain a PromptPlan history.
