## Pronoun-heavy retrieval

Exact source:

\`\`\`text
Eris carried the Sun Blade. She left it there.
\`\`\`

remains byte-for-byte authored source.

The retrieval-only source representation adds title, Tree path, and learned entity context.

Both of these can retrieve the source:

- \`She left it there\`;
- \`Eris Sun Blade left\`.

No authored text is rewritten.

## Incremental edit result

Changing one deep UID:

\`\`\`text
Mara owns the Ember Tavern.
->
Mara formerly owned the Ember Tavern.
\`\`\`

causes:

- new exact source revision through Wave 1;
- leaf NavigationSummary staleness;
- dependent ancestor staleness;
- source-dependent corpus/community staleness where applicable;
- new grounded historical summary content;
- old summary history preservation;
- unrelated branch summary identity reuse.

## Tree-only reorganization

Moving an unchanged source from one Tree path to another:

- preserves exact source prose;
- creates the source revision required by structural metadata change;
- removes the old navigation membership;
- creates the new navigation membership;
- invalidates only scopes whose structural/source dependency set changed;
- preserves unrelated branch summaries.

Tree placement never becomes claim authority.

## Child failure behavior

A forced deterministic provider failure at one leaf proves:

- the leaf does not publish a false valid summary;
- its direct parent is blocked;
- ancestors depending on the failed child are blocked;
- an unrelated sibling branch still publishes successfully;
- no stale child is used to leave a parent falsely current.
